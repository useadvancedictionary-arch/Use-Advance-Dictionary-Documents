Account and Data Deletion — SubjectZone

Application: SubjectZone  |  Package: com.subjectzone.app  |  Updated: October 31, 2026

SubjectZone does not create accounts

The App has no sign-up, login, profile, or cloud sync. No personal data is stored on our servers, so there is no account to delete and no server-side data to erase. Any information on your device is limited to the App’s own installed files and cache, and you can remove it in seconds using the steps below.

This page is provided so that users can find deletion instructions and request confirmation, in line with Google Play’s user data policies.

1. Delete All App Data on Android

Option A — Clear storage (keeps the App installed)

1
Open your device’s Settings.
2
Tap Apps (or Apps & notifications) → SubjectZone.
3
Tap Storage & cache → Clear storage (or Clear data), then Clear cache.
4
If you also granted microphone permission, you can withdraw it on the same screen under Permissions → Microphone.

Option B — Uninstall the App

Long-press the SubjectZone icon and choose Uninstall, or use Settings → Apps → SubjectZone → Uninstall. Uninstalling removes all application files and cache from your device immediately.

2. Delete App Data on Windows

  1. Open Settings → Apps → Installed apps (or Apps & features in Control Panel).
  2. Find SubjectZone, choose Uninstall, and confirm.
  3. Optionally remove any remaining folder under %LOCALAPPDATA% that carries the SubjectZone name.

Uninstalling removes the installed program and its local cache. SubjectZone does not keep a Windows user profile, document library, or cloud backup.

3. Delete App Data in the Web Edition

  1. Open your browser’s Site settings for the SubjectZone web address.
  2. Choose Clear data (or Delete site data).
  3. If you allowed microphone access for voice search, revoke it in the same panel.

The web edition stores no account information. Its files and cache live in your browser and are removed by the browser’s own site-data controls.

4. Data Types and Deletion Breakdown

Data Category Where It Lives How It Is Deleted
Account, profile, or login credentials Not collected — SubjectZone has no accounts. Nothing to delete. No such record exists.
Cloud-synced progress or bookmarks Not collected — there is no cloud sync. Nothing to delete. No server database is operated.
Installed application files and cache Your own device or browser. Clear storage in device settings, clear site data, or uninstall. Instant.
Library position and on-screen state Memory only, while the App is open. Discarded automatically when the App closes.
Voice-search audio / transcripts Not stored by SubjectZone; speech recognition is handled by your browser or operating system. Nothing retained by us. Manage your provider’s voice settings if you wish to clear its history.
Support emails you send us Our support mailbox, only if you contact us. Deleted when the request is handled, or on request — see Section 5.

5. Request Confirmation or Deletion of an Email You Sent

If you have contacted us and want your message and email address removed from our support mailbox, send a deletion request:

Email our support team

1
Write to useadvancedictionary@gmail.com.
2
Use the subject line: Data Deletion Request - SubjectZone.
3
Send the request from the same email address you used before, so we can locate the message. If you no longer have access to it, describe the earlier conversation and we will do our best to help.

We will acknowledge the request within 7 days and delete the related email correspondence within 30 days, except where a record must be kept to comply with the law. Because SubjectZone has no user accounts, there is no other record to remove.

6. Processing Timeline

  • On-device data: deleted immediately when you clear storage or uninstall.
  • Support mailbox data: acknowledged within 7 days and deleted within 30 days of a verified request.
  • Server-side account data: not applicable — no account or cloud database exists.
⚠️ Please note: Clearing storage or uninstalling is irreversible. The App keeps no backup, so any on-screen state or cached content will not be recoverable. Your textbook solutions remain available after reinstalling, because they are bundled with the App.
